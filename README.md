# Sistema de Gestión de Operaciones y Rentabilidad (BI) - Excel

## 📌 Descripción del Proyecto
Este proyecto consistió en el diseño y desarrollo de una solución integral en Excel para una empresa de servicios en Estados Unidos. El objetivo principal fue centralizar la información operativa y financiera para permitir una toma de decisiones basada en datos.

## 🛠️ Herramientas Utilizadas
* **Excel Avanzado:** Tablas dinámicas, Power Query para limpieza de datos y funciones lógicas complejas.
* **Análisis de Negocio:** Seguimiento de KPIs financieros y operativos.

## 📊 Módulos del Sistema
1. **Control de Clientes y Recurrencia (Churn Analysis):** Monitoreo de servicios activos, altas y cancelaciones para medir la retención.
2. **Gestión de Servicios Únicos:** Registro independiente de ingresos no recurrentes por mes.
3. **Módulo de Nómina:** Cálculo automatizado de pagos a empleados basado en servicios realizados.
4. **Cortes de Contabilidad:** Reportes automáticos de ganancias netas con cierres:
   * Mensuales
   * Cuatrimestrales
   * Anual

## 📈 Resultados e Impacto
* **Visibilidad Financiera:** El cliente obtuvo una visión clara de su margen de ganancia real después de impuestos y nómina.
* **Control de Cancelaciones:** Identificación de patrones en la pérdida de clientes para mejorar la retención.
* **Automatización:** Reducción del tiempo manual dedicado a la contabilidad operativa mediante la estructuración de hojas por mes y periodos.
